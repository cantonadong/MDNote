# MDNote 开发文档

对应需求原文见 `../need.md`，开发规范见 `../dev规范.txt`。本文档描述架构、业务流程、页面/交互细节，作为后续迭代的基准。

## 1. 产品定位

Win10+ 桌面 Markdown 编辑器，WYSIWYG（所见即所得）编辑体验，绿色便携、低资源占用，视觉风格对齐 Notion。

## 2. 技术架构

| 层 | 选型 | 说明 |
|---|---|---|
| 外壳/运行时 | **Go + Wails v2**（原方案 Tauri 2 + Rust 已废弃） | 复用系统 WebView2，无内置 Chromium；Go 运行时/GC 比 Electron 轻量得多，产出单个便携 exe（~11MB，`-ldflags "-s -w"` 去符号表） |
| 前端框架 | Svelte 5 + TypeScript + Vite（SvelteKit，`adapter-static` 输出 SPA） | 编译期产出，无虚拟 DOM 运行时开销 |
| 编辑器核心 | `@tiptap/core` + `@tiptap/starter-kit` 3.28.x，另加 `@tiptap/extension-task-list`/`task-item`/`table`/`table-row`/`table-cell`/`table-header` | 基于 ProseMirror，自带 heading/list/blockquote/codeblock 等 markdown 输入规则；任务列表与表格用官方扩展 |
| 自定义节点 | `frontend/src/lib/editor/nodes/`：`toggleList.ts`（折叠块，`<details>/<summary>` + NodeView 同步 open 状态）、`callout.ts`（高亮块）、`links.ts`（`pageLink`/`fileLink` 行内 chip + 点击处理插件）、`slashTrigger.ts`（`/`、空格触发菜单的 ProseMirror 插件） | 标准 Tiptap 没有对应节点，按需现写；均无自带 markdown 语法 |
| Markdown 转换 | `tiptap-markdown`（`Markdown.configure({ html: true, ... })`） | 文档 ↔ Tiptap JSON 双向转换；`html:true` 让 toggleList/callout/pageLink/fileLink 这类无 markdown 语法的自定义节点走"原始 HTML 直通"兜底序列化/解析（tiptap-markdown 未显式注册 `storage.markdown` 的节点默认如此），无需手写序列化器 |
| 文件系统 | Go 侧 `fsops.go`（`ListDir/ReadFile/WriteFile/CreateEntry/RenameEntry/DeleteEntry/MoveEntry`） | 目录树增删改移一律显式校验目标路径落在用户选定根目录内（`withinRoot`），防越权 |
| 设置持久化 | `<exe目录>\config.ini`（`settings.go`，`[General]` 节 `RootDir=` 键） | INI 明文、`exe` 同目录、不写注册表/AppData，保证绿色可删除，也方便用户直接打开确认/手改根目录指向的真实系统路径 |
| 打包交付 | `wails build` 产出便携 `build\bin\MDNote.exe`（不生成安装包） | 依赖系统已装 WebView2 Runtime；前后端通信走 Wails 自动生成的 `window.go.main.App.*` 绑定（本项目手写了等价的 `frontend/src/lib/api.ts` 薄封装，未依赖 `wails generate` 产物） |

## 3. 目录结构

```
D:\Dev\MDNote\
  need.md / dev规范.txt        # 需求与规范原文
  docs\开发文档.md / 开发日志.md
  wails.json                   # Wails 项目配置
  main.go / app.go             # 入口、窗口配置、Wails 绑定的 App 结构体（对话框/设置）

  settings.go                  # 便携化配置读写
  frontend\                    # SvelteKit 前端（Vite 项目根，Wails 约定目录）
    src\
      app.css                  # 全局样式变量（Notion 风配色）
      routes\+page.svelte       # 应用主布局
      lib\

        appState.svelte.ts       # 全局响应式状态（标签页/设置/选中目录/弹窗）（Svelte 5 runes）
        wordcount.ts              # 中文按字 / 英文按词 统计
        components\               # Sidebar / TreeNode / Tabs / Toolbar / Editor / Outline / StatusBar / FindReplace / ConfirmDialog / Toast / Icon
        editor\                   # bridge（编辑器实例句柄）、outline、searchHighlight（查找高亮插件）、slashMenu.svelte.ts（斜杠菜单共享状态）
          nodes\                    # toggleList / callout / links（pageLink、fileLink）/ slashTrigger 自定义 Tiptap 扩展
    dist\                       # 构建产物，go:embed 嵌入 exe（.gitignore）
  build\bin\MDNote.exe         # wails build 产物（.gitignore）
  build\bin\config.ini         # 运行期便携配置（.gitignore，首启生成，随 exe 同目录）
```

## 4. 业务流程

1. 首次启动：`config.ini`（exe 同目录）不存在 → 左栏显示"选择根目录"空态 → 用户通过系统目录选择对话框选定根目录 → 写入 `config.ini` 的 `RootDir=` → 左栏懒加载展示目录树（子目录点击展开时才 `ListDir`）。
2. 目录树只展示 markdown 相关节点：`ListDir` 只返回 `.md` 文件、以及递归包含至少一个 `.md` 文件的子目录；文件节点显示名去掉 `.md` 后缀。
3. 目录树选中态：点击目录/文件节点即选中并高亮（与"展开"是独立的两个状态）；工具栏"新建文件夹"/"新建文件"作用于当前选中目录 —— 选中的是文件则取其所在目录，未选中任何节点则默认作用于根目录。
4. 打开文件：点击左栏文件节点，或工具栏"打开"选择任意 md 文件 → 若已在某个标签打开则激活该标签，否则新建标签、读取文件文本 → `tiptap-markdown` 解析为文档渲染到中栏编辑区。
5. 编辑：用户输入触发 StarterKit 的 markdown 输入规则实时转换显示样式；每次文档变更（debounce ~200ms）→ 重算右栏大纲、底部字数、当前标签脏标记。当前光标所在块左侧浮现"添加"按钮（Notion 风块手柄）；点击该按钮，或在块首输入 `空格`/`/`，弹出块类型菜单，选中后在当前块下方插入并聚焦。菜单类型覆盖：文本、标题1-4、bullet list、number list、todo list、toggle list、callout、quote、table、分割线、新 page、page link、file link（详见 §7 待实现清单，当前仅实现其中一部分）。
6. 保存：工具栏"保存"→ 若为已存在文件路径的标签，直接 `getMarkdown()` 写回原路径；若是新建（无路径）标签，则走"另存"→系统保存对话框，默认初始目录为左栏当前选中的目录（未选中则为根目录）。
7. 关闭标签：点击关闭或中键点击 → 若脏 → 弹出"保存/不保存/取消" → 保存则先执行保存流程再关闭，不保存直接关闭，取消则不关闭。若该标签对应文件在外部已被实际删除（见第 9 条），关闭时改为提示"文件已被删除，是否另存为新文件"。
8. 目录树增删改移：新建文件/文件夹（`window.prompt` 输入名称）、重命名（内联编辑）、删除（二次确认弹窗）、拖拽移动（松手后校验目标非自身子孙、调用 `MoveEntry`，同时同步已打开标签的路径）。
9. 外部文件丢失检测：已打开文件若在磁盘上被外部删除/移走，对应标签显示红色圆点标记（区别于"未保存"的普通脏点）；检测时机建议为切换到该标签、或保存该标签时按需 `stat` 校验路径是否仍存在（避免为每个打开的标签轮询）。
10. 标签排序：支持拖拽标签调整左右顺序（更新前端标签数组顺序，不影响磁盘路径）；标签总宽度超出可视区域时支持鼠标滚轮触发横向滚动。
11. 查找/替换：工具栏图标打开条状面板 → 输入关键字实时用 ProseMirror decoration（`searchHighlight.ts`）高亮命中项并可上一个/下一个跳转 → 替换/全部替换通过编辑器事务原地替换文本。

## 5. 页面/交互细节

- **左栏**：目录树（仅 md 相关节点，文件名隐藏 `.md` 后缀），图标区分文件夹/文件；节点支持点击选中并高亮（选中态持久显示，与展开态独立）；右键菜单（新建文件/新建文件夹/重命名/删除）；工具栏"新建文件/文件夹"作用于当前选中目录；拖拽时高亮目标目录；子目录懒加载；提供手动"刷新"入口感知外部改动。
- **标签栏**：位于**最上方**；每个标签仅显示文件名（不含 `.md` 后缀）+ 关闭×；未保存显示圆点脏标记；文件在外部已被删除则显示**红色**圆点标记（互斥优先于普通脏标记显示）；支持拖拽调整标签前后顺序；标签总宽超出可视区域时支持鼠标滚轮横向滚动；末尾 `+` 按钮=新建；鼠标中键点击=关闭；关闭脏标签弹二次确认，关闭"已被外部删除"的标签弹"是否另存为新文件"确认。
- **功能区（工具栏）**：位于标签栏**下方**；图标顺序为 打开、新建、保存、另存、查找、替换、撤销、重做，共 8 个图标按钮，纯图标+tooltip。
- **中栏编辑区**：视口内始终居中，内容列固定 1000px 宽；字体使用系统默认；当前块左侧浮现"添加"按钮 + Notion 风块类型菜单（触发方式：点击按钮 / 块首输入空格 / 块首输入 `/`）；另存对话框默认定位到左栏当前选中目录。
- **右栏**：H1–H6 大纲缩进列表，随内容 debounce ~200ms 更新；点击跳转并定位标题。
- **底部状态栏**：字数 = 中文按字符数 + 英文按空格分词的词数 累加，debounce ~200ms 更新。
- **整体视觉**：Notion 风——浅灰侧栏（`#fbfbfa`）、白色内容区、细边框分隔、无边框图标按钮 + hover 高亮、圆角卡片式菜单/弹窗。

## 6. 已知待打磨项（不影响当前可用测试版）

- 新建文件/文件夹当前用 `window.prompt`（浏览器原生弹窗，非 Notion 风格内联输入），后续可换成与"重命名"一致的内联输入框。"新 page" 命名也复用同一 `window.prompt`。
- Sidebar/TreeNode 存在若干 a11y lint 警告（拖拽容器缺少 ARIA role、`autofocus` 用法），不影响功能，后续可按需补充。
- 未做体积/UPX 进一步压缩（本机未安装 upx.exe）；如需更小可后续安装 upx 并加 `-upx` 参数。
- 未做自动化测试；已通过 `wails build` 编译产物实机启动 + 截图验证（DPI 感知下目录选中高亮、工具栏图标顺序、斜杠菜单弹出/过滤/高亮/选中插入均确认渲染正常；受当前工具环境限制，table/toggleList/callout/pageLink/fileLink 的最终视觉与 markdown 落盘往返未做逐项截图，仅代码走查 + `svelte-check`/`vite build`/`go build` 静态验证）。
- `pageLink`/`fileLink` 节点把目标路径存成绝对路径快照：目标文件之后若被重命名/移动，已插入文档里的引用不会跟着更新（该文件被删除时，只有作为"当前打开标签"时才会被检测到，链接本身不会主动失效提示）。
- `toggleList`/`callout`/`pageLink`/`fileLink` 没有对应的标准 markdown 语法，落盘的 `.md` 文件里会以裸 HTML 标签（`<details>`/`<summary>`、`<div data-type="callout">`、`<a data-type="page-link">` 等）保存；这是 `tiptap-markdown` 在 `html:true` 下的原始 HTML 直通兜底行为，不是 bug，但意味着这几种块类型在纯文本/其他 markdown 工具里打开会显示为 HTML 源码而非渲染效果。

## 7. 本轮已实现（对应 2026-07-23 need.md 更新）

- 目录树选中态：`appState.selectedEntry`，点击目录/文件高亮并作为"新建文件/文件夹"和"另存为"对话框默认目录的依据（`targetDirForNewEntry()`）。
- 标签栏：原生 HTML5 drag events 实现拖拽排序（`appState.reorderTab`）；`wheel` 事件转 `scrollLeft` 实现横向滚动；标签标题统一在渲染层去掉 `.md` 后缀（`stripMdExt`，此前是把带扩展名的文件名直接存进 `tab.title` 显示的遗留 bug）。
- 外部文件删除检测：Go 侧新增 `FileExists`；切换到某标签或关闭前用它做一次 `stat`；命中则标签显示红点，关闭时走"另存为新文件"分支（而非直接覆盖写回旧路径）。
- 保存/另存对话框：Go 侧 `SaveFileDialog` 新增 `defaultDir` 参数（映射 Wails `SaveDialogOptions.DefaultDirectory`），前端传入 `targetDirForNewEntry()`。
- 工具栏图标顺序调整为：打开、新建、保存、另存、查找、替换、撤销、重做。
- 斜杠菜单：`nodes/slashTrigger.ts` 是一个注册在 StarterKit **之前**的 ProseMirror 插件（顺序很关键，见该文件注释），拦截空格/`/`/方向键/Enter/Esc；`Editor.svelte` 里 `slashMenuState`（`editor/slashMenu.svelte.ts`）驱动弹出的过滤/高亮 UI，选中后用 `insertContentAt({from, to}, content)` 整块替换当前（已清空的）block。同一套 `buildBlockContent()` 也被"+"块手柄菜单复用，区别只是插入位置（替换当前块 vs. 插入到当前块之后）。
- 菜单类型覆盖 17 项：文本、标题 1-4、bullet list、number list、todo list（`@tiptap/extension-task-list`+`task-item`）、toggle list（自定义 `<details>/<summary>` 节点 + NodeView 同步展开状态）、callout（自定义容器节点）、quote、代码块、table（`@tiptap/extension-table` 系列，v3.28 自带 markdown 表格序列化）、分割线、新 page（`appState.createNewPageNear()`：在当前文件同目录下 `CreateEntry` 一个新 `.md` 并作为标签打开）、page link（`appState.pickPageLink()`：`OpenFileDialog` 选取 `.md`）、file link（`appState.pickFileLink()`：新增 Go `OpenAnyFileDialog` 选任意文件；点击用新增 Go `OpenWithDefaultApp`，Windows 上走 `cmd /c start`）。page link / file link 都渲染成行内 chip 节点（`nodes/links.ts`），点击行为通过一个 `handleClickOn` ProseMirror 插件统一处理，而不是逐节点写 NodeView。
