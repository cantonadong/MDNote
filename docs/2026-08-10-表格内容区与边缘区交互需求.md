# 表格内容区与边缘区交互需求

## 目标

每个表格单元格分为两个互斥命中区域：

- 内容区：由单元格内段落的整条内侧文本行决定（包括文字右侧同一行的空白），鼠标为 I 型；点击定位光标，按住拖动选择文字。
- 边缘区：单元格边框内、内容区外的留白，鼠标为普通箭头；按下立即选择整个单元格，按住向任意方向拖动形成矩形多单元格选区。

选中的一个或多个单元格使用浅蓝底色，并只在整个矩形选区的最外缘绘制 2px 蓝色边框。

## 状态与边界

- 短文本、长文本、多行文本：每个段落的整条横向行盒属于内容区，不只限于文字字形。
- 空单元格：整条内侧行高区域都是可编辑内容区，仍可在任意横向位置放置输入光标；四周 padding 留白属于边缘区。
- 链接等行内内容：属于内容区。
- 鼠标从边缘区开始的手势全程归单元格选择处理；从内容区开始的手势全程归浏览器文本选择处理，中途不得抢夺。
- 文本选择过程中不得修改 contenteditable 内部 DOM。

## 开发顺序

1. 独立 Preview 用 mock 表格确认区域、光标、点击和拖选。
2. 用户确认 Preview。
3. 将同一命中规则接入 ProseMirror 插件，以单一事件所有者处理完整指针序列。
4. 在实际 WebView2 中复测文本选择、空白点击、横向/纵向/矩形拖选。

## 回滚边界

Preview 与真实编辑器隔离。用户确认前不修改 `Editor.svelte` 和 `table.ts` 的生产鼠标事件链；删除 Preview 路由即可完整回滚本阶段。
