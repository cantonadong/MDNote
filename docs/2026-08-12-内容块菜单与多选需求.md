# 内容块菜单与多选需求

## 目标与业务流程

1. 每个内容块左侧保留“+”与六点拖拽按钮。
2. 单击六点按钮后，高亮当前内容块，并弹出一级菜单；一级菜单只包含“复制”和“转换为”。
3. 单击“复制”复制当前内容块的全部内容，不改变块格式或正文。
4. 鼠标移入“转换为”后，在一级菜单右侧展开竖向二级菜单，列出编辑器支持的全部块格式。
5. 单击二级菜单中的格式后，将当前内容块的全部内容原位转换为该格式，并关闭菜单；可保留的文本与行内样式应尽量保留。
6. 在内容区左侧空白处按下鼠标并上下拖动，选择经过的多个完整内容块；每个选中块分别显示蓝色圆角高亮。向上、向下拖选均有效，松开后保持选择。

## 交互边界

- 六点按钮移动超过拖拽阈值时仍执行块排序，不打开菜单；未超过阈值才视为单击。
- 二级菜单在鼠标位于“转换为”或二级菜单内部时保持展开，移出后收起。
- 点击编辑区其它位置或按 Escape 关闭菜单/取消整块多选。
- 从正文文字区域按下仍归正文编辑器处理，不能触发整块多选。
- 表格块沿用已有表格专用菜单；本次通用菜单适用于其它内容块。
- 不支持内容保持的目标格式应在真实接入时禁用或明确处理，不能静默丢失内容。

## 视觉

- 一级、二级菜单使用现有内容块菜单的背景、边框、圆角、阴影、字号和 hover 色。
- “转换为”右侧显示箭头；二级菜单为单列竖向列表，可滚动，和一级菜单间留 4px。
- 多块选择采用每块独立的 `rgba(35, 131, 226, 0.13)` 蓝色圆角覆盖层，不合并成一个大矩形。

## 开发顺序与依赖

1. 独立 Preview：用 mock 内容覆盖菜单关闭、一级菜单、二级菜单、已复制反馈、多块选择和长列表滚动。
2. 用户确认视觉与交互。
3. 接入 `Editor.svelte`：增加菜单层级状态、块复制命令、格式转换路由，并复用既有整块多选实现。
4. 执行 `npm run check` 和 `npm run build`；真实 WebView2 鼠标手势由用户复测。

## 验收用例

1. 单击普通段落六点按钮，只出现“复制”“转换为”。
2. 移入“转换为”，右侧出现全部格式的竖向菜单；可正常滚动并点击。
3. 复制后剪贴板内容与该块完整内容一致，正文不变。
4. 将含多行文字的块转换为标题/列表/引用等支持格式，文字不丢失且格式立即变化。
5. 从左侧空白处由第一块拖到第三块，三块分别蓝色高亮；反向拖动结果一致。
6. 从正文起拖只选择文字，不触发整块蓝色高亮。
7. 拖动六点按钮排序时不误开菜单。
